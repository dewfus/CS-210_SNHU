# CS-210_SNHU

# Summarize the project and what problem it was solving.

This project was solving a problem with understanding how an investment can grow over time. Sometimes when investing money, it can be difficult to see how your wealth will be impacted in the future. This project allows an individual to input specific information and see how a small investment will accumulate a great deal of wealth in the future.

# What did you do particularly well?

Personally I feel I did particularly well on validating the user input. Using the validation to determine whether the number is indeed a number and whether it is above 0 in some circumstances, while allowing 0 in others (but not negative numbers).

# Where could you enhance your code? How would these improvements make your code more efficient, secure, etc?

Based on feedback, it appears I could enhance my code with more accurate calculations. The improvement in that way can help my code provide more accurate results when estimating where an initial investment can end up over a range of years.
